GET STARTED

A workspace for trying part.

Choose an example, edit the prompt, then send it. The scripted provider makes every example repeatable without an API key.

  1. Requests shows exact encoded model input and digest, without authentication headers.
  2. Events follows tool execution, approvals and final run state.
  3. Note changes only after you approve a save_note call.
  4. Items uses the public Inspector. Open a report and choose Load artifact to read its immutable bytes.

Try Stop during a long response. Reconnect and page refresh restore server memory; closing the tab only stops observation. Clear session resets conversation context, notes and reports after the active run ends.

Use your provider

Set R4U_API_KEY and R4U_BASE_URL in the workspace .env, then restart. Select Chat Completions or Responses and enter a model available to your route. Sending a message makes real provider requests. Each run permits at most four model requests and 512 requested output tokens per request.

Rich cards and Dark change presentation without restarting runs. Full documentation: docs/playground.md.
